Довести README §3.2/§3.5/§3.6 (тип позиции → матрица закрытия → «не требуется» → умные акты) до сквозного вида:

```
Загрузка РД → тип позиции (работа / материал / оборудование)

```

## 2. Матрица закрытия (решение заказчика, 10.09.2026)

| Тип позиции | Паспорт/Сертификат | АВК | АОСР | ВСО | ВР |
|---|---|---|---|---|---|
| Материал | требуется | требуется | требуется | не требуется | не требуется |
| Оборудование | требуется | требуется | не требуется | требуется | не требуется |
| Работа | не требуется | не требуется | не требуется | не требуется | требуется |

Следствия:
1. **Знаменатели дашборда:** АВК = материалы + оборудование; АОСР = **материалы**; ВСО = **оборудование**; ВР = работы.
2. Статистика «с паспортом / без паспорта» считается только по типам, которым паспорт требуется (материал, оборудование); работы исключаются.
3. Неподходящий тип акта → ячейка серая (⚪ палитра DESIGN), а не красная.
4. Работы не участвуют в АВК/АОСР/ВСО; материалы и оборудование не участвуют в ВР.

**Расхождение с текущим ТЗ (исправить в S4-13):** README §3.5 («работа — АОСР и ВР»),
§3.6 («АОСР и ВР — работы») и §1.1 (АОСР описан как акт на скрытые работы). По решению заказчика
АОСР закрывает **материалы**, работы закрывает только **ВР**.
